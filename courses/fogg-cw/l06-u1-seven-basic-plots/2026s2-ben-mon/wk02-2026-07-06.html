辩论 · 伏地魔算不算「怪物」?人也能是怪物

12:10 – 15:40
要点
  • Ben 问:列表上「怪物威胁的东西(至亲、朋友、家人、生命、家园)」有没有漏掉的?Yihan 抛出一个问题:伏地魔其实是个人类。由此展开一场辩论——一个人类算不算怪物
  • Yihan 的立场:他本人不是怪物,但他把别人变成怪物(还把自己的脸长在别人后脑勺上,指《魔法石》里的奇洛)。Ben 反问:难道「怪物」一定要是另一个物种、异类吗?他认为人类完全可能、甚至更有可能成为真正的怪物
  • Kathleen 说:怪物就是想法邪恶、不按正确方式思考的人。Ben 借此点出难点——一旦说「有正确的思考方式」,就会踩进「是否存在普世价值」的泥潭;但跨文化确实有些事几乎人人都认定是邪恶的,做这些事(有时纯为取乐)的人,我们可以说是 monstrous。结论:写这种情节时,怪物不一定住在桥下、床下或洞里——怪物也走在我们的城市里,有时我们叫他们 psychopath(精神变态者)
💡 这节在教什么
  • 这是全课思维含量最高的一段。Ben 把一个儿童题材(打怪)推到伦理层面:「怪物」是一个象征、类比的说法,而不是生物学分类。当我们叫某人「怪物」,指的是残忍、扭曲、恶毒,而不是另一个物种。
  • 他处理 Yihan 的反驳方式值得学:不是否定,而是「把你的观点推下去(push this point)」,顺着学生的逻辑往前逼一步,逼出「monster = other 异类」这个隐含假设,再拆掉它。这是把学生的话当成思考材料,而不是对错判断。
  • 如果你是外人、想自己练:想一个你觉得「是怪物」的反派,写下他到底威胁了什么、他的「怪物性」是外形上的还是心里的——你会发现最可怕的往往是后者。

焦点问题 · 什么造就一个好反派?从伏地魔的外形说起

15:40 – 18:10
要点
  • Ben 抛出今天的焦点问题:What makes a good villain?(什么造就一个好反派?)先不读材料,让大家凭直觉说——一个令人难忘、有说服力的反派需要哪些特质,作者在设计时考虑了什么

  • Ben 顺着拆解:灰皮肤立刻暗示疾病、精神上的深层病态;鼻子扁平,整张脸被做得像一条蛇、一只爬行动物。他追问爬行动物和哺乳动物的区别——Kathleen 猜「黏滑」「移动很顺滑」,Ben 都否掉;Ruby 答「冷」。答案是冷血(cold-blooded):把反派和爬行动物关联,就是在暗示他血是冷的、没有心
💡 这节在教什么
  • 这一段是把「抽象印象」变成「可分析的设计选择」的示范。Kathleen 只说「记得他的样子」,Ben 一步步逼她说出具体特征,再解释每一个外形细节背后的象征逻辑:灰=病态,蛇=冷血无心。这就是创意写作里最关键的能力——看出「作者为什么这样选」。
  • Ben 用一连串提问(爬行动物为什么可怕→不是黏滑→是冷血)把课堂变成推理游戏,而不是直接给答案。学生答错了(黏滑、顺滑)也被认真对待,最后由 Ruby 答对。这让「找答案」本身变成参与。
  • 如果你是外人、想自己练:挑一个你熟悉的反派,列出他的三个外形细节,逼自己写出每个细节「在暗示什么」——外形从来不是随便画的。

专业课程评析 · 以世界级课程分析师的视角

课后复盘
要点
  • 以下是站在「世界级创意写作课程分析师」角度的复盘,供你(老师/学习者/家长)参考,不是课堂原话。
  • 这堂课好不好? —— 结构扎实。骨架清晰:从「什么造就好反派/怪物」→ 一个有名有姓的名家范本(达尔《玛蒂尔达》里的 Trunchbull)→ 直接进入 15 分钟学生自己写反派 → 分享与针对性反馈。Ben 始终在「抽象套路 → 具体范例 → 亲手产出」之间移动,并用一个追问(「弱点是什么?怎么相遇?」)把学生从「画像」推向「情节」。热身也做得好:先让每个孩子 calm and safe、先开口,再进入创作。
  • 它到底教了什么? —— 三件可迁移的事:①把反派设计当成一份「套路菜单」(魔法型 / 统治世界的阴谋家 / 强壮但笨的打手),每种都自带一个弱点;②好描写怎么运作——堆叠具体身体细节、给每个细节配一个泄露性格的形容词、拟人化(「倔强的下巴」)、再用一个鲜明的明喻定调(「像冲锋队员一样行军」);③一条规则:反派必须有弱点、必须有与主角相遇的接触点,否则没有情节。术语:protagonist / antagonist / villain / monster / trope / henchman / simile / metaphor / personification / unreliable narrator。
  • 哪里不好 / 哪里可以做得更好?(必读) —— ①时间与标准不对称:主角环节(五个学生各自分享)偏长,且停在「起名字、贴标签」层面(「一个勇敢的女孩」「一个魔法师」),Ben 没有像后面要求达尔那样,回头要求学生给出同样的「具体细节」标准——反派分析享受了精细待遇,主角分享却没有。建议:主角分享时就用同一把尺子追问「给我一个身体细节 + 一个形容词」。②发言不均:达尔那段分析和课末反派分享大多由 Kathleen 一人承担;较安静的学生(如 Yuxi、Ruby、Yihan)几乎没被带进深度环节。建议:用快速轮流或直接点名(「Ruby,达尔用了哪个细节?」)把发言摊开。③写作没有逐一验收:15 分钟写作后只有一位自愿者分享,大多数学生的草稿从没在课上被拿出来或纠正,手法被示范了却没落到每个人自己的文字上。建议:留最后 5 分钟做「每人读一句最好的描写」的快速轮转。
  • 我怎样才能学会? —— 把这堂课当成一个循环来做,而不是听讲:选一种反派套路 → 在你喜欢的书里找一段人物写得生动的段落 → 不要抄,用自己的话列出作者用了哪些具体细节、形容词、明喻 → 用同样的招数写你自己的人物 → 最后回答「弱点是什么」「主角怎么遇见他」。
  • 能应用在哪? —— 任何叙事写作:考试写故事、比赛投稿、小说,甚至游戏/桌游的人物设计。「每个细节都带一个泄露性格的形容词」这条原则,也能让写景写人的记叙文更利落,甚至用在个人陈述里把一个人写得鲜活。
💡 这节在教什么
  • 这堂课的设计逻辑(值得备课借鉴):热身调节情绪(calm and safe)→ 读海报练「读图即读故事、推断作者意图」→ 放《瑞克和莫蒂》片段,让学生自己归纳出「打败怪物」这一情节 → 由怪物延伸到「怪物可能在人心里」→ 辩论「伏地魔算不算怪物」深化人性思考 → 先造主角、再造反派 → 用达尔的 Trunchbull 做范文拆解手法 → 15 分钟动笔 → 分享 + 针对性反馈 → 作业只是课堂动作的放大。整堂课本身复刻了它所教的写作流程:观察范本 → 命名技法 → 自己产出 → 获得反馈。
  • Ben 的两个好习惯:①锚定在一个有名、略带滑稽的反派(Trunchbull)上,让分析具体、好记,而不是抽象罗列规则;②反馈不停在夸奖,而是用一个追问把学生往情节推(弱点 + 相遇)。作业特意给了选择(主角或反派),既降低门槛,又仍然强制应用。

So in quite a short package, he's managed to do a lot. — good description is not about writing more, but about making every word work: each detail must leak character.「所以在相当短的篇幅里,他做成了很多事。」——这既是 Ben 对达尔的评价,也是这堂课想教给学生的写作标准:不是写得多,而是每个词都在工作,每个细节都在传达性格。
